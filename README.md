# Restaurant UI Prototype

A frontend learning project containing restaurant and food-ordering interface experiments built with HTML, JavaScript, and utility-first styling.

## Overview

This repository is an early web-development prototype focused on practicing:

- Responsive restaurant layouts
- Menu and product presentation
- Shopping-cart interactions
- Contact and location sections
- Basic JavaScript DOM manipulation
- Tailwind CSS based UI styling
